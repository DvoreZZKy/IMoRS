# IMoRS - ГАВНО

**IMoRS** (Interactive Map Object Rendering System) — десктопное приложение для Windows
для создания и управления пользовательскими метками на интерактивной карте.
Добавляйте точки на карту OpenStreetMap, назначайте им иконки (встроенные или
свои изображения), задавайте описание и размер, а все данные храните локально
в SQLite. Поддерживается экспорт и импорт меток вместе с иконками.

Приложение написано на **C#** с использованием **Avalonia UI** и архитектуры **MVVM**,
карта построена на **Mapsui + BruTile**, хранение — **SQLite + Entity Framework Core**.

> **Ключевые слова:** карта, метки на карте, OpenStreetMap, Mapsui, Avalonia,
> .NET, C#, desktop, SQLite, GIS, markers, map editor, DvoreZZKy.

## Возможности

- **Карта** на базе Mapsui с подложкой OpenStreetMap.
- **Метки**:
  - добавление по клику на карте (с наглядной временной меткой);
  - редактирование описания;
  - изменение размера;
  - удаление;
  - **динамический размер**: иконки меток плавно увеличиваются при приближении и уменьшаются при отдалении карты;
  - **экспорт/импорт**: теперь иконки сохраняются прямо в JSON-файл (в формате Base64), поэтому вы можете передать файл другу, и он увидит ваши метки с картинками.
- **Иконки**:
  - встроенный набор иконок (дорожные знаки);
  - добавление собственных изображений (JPG, JPEG, PNG, BMP, GIF);
- **Хранение данных**: локальная база SQLite. Метки сохраняются между запусками.
- **Кастомный интерфейс**: окно без системной рамки, собственные кнопки управления, исправлено поведение сворачивания из полноэкранного режима.
- **Анимации**: плавное появление при запуске, выдвижение панелей, открытие списка иконок.

## Требования

- Windows 10+

## Установка

1. Скачайте последний релиз из раздела [Releases](../../releases) (файл `IMoRS.exe`).
2. Запустите `IMoRS.exe`.

> ⚠️ **Важно при первом запуске:**  
> Так как файл не подписан цифровым сертификатом, Windows SmartScreen может показать предупреждение: *«Windows защитила ваш компьютер. Приложение может быть опасным»*.  
> Это нормальная реакция системы на неподписанные `.exe`-файлы.  
> Чтобы запустить приложение, нажмите **«Подробнее»** → **«Выполнить в любом случае»**.  
> Приложение не содержит вирусов, весь исходный код открыт в этом репозитории.
